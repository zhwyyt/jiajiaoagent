# Backend

Node.js + TypeScript backend for the Android MVP.

## Responsibilities

- expose HTTP API for voice conversation sessions
- call Hermes orchestration modules
- manage session state integration points
- return normalized payloads for the Android client

## Planned Modules

- `src/server/` HTTP server bootstrap
- `src/routes/` API routes
- `src/hermes/` orchestration modules
- `src/services/` application services
- `src/storage/` storage abstractions and access helpers
- `src/types/` shared TypeScript payload types
- `db/migrations/` SQL migration drafts
