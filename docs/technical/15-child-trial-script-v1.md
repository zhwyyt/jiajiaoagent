# Child Trial Script V1

## Purpose

Provide a small repeatable real-child trial script for the current V1 mainline:

`QQBot + Hermes + jiajiaoagent backend bridge`

This script is for early feasibility validation, not formal pedagogy evaluation.

The goal is to learn:

1. Will the child willingly speak to the tutor?
2. Can the child keep going for several turns without strong adult rescue?
3. Which topic types create the best speaking flow?
4. Where does the child get stuck: vocabulary, confidence, sentence length, or attention?

## Trial Format

Recommended first-trial length:

- `8 to 12 minutes`

Recommended participants:

- `1 child`
- `1 parent or adult observer`

Recommended device/setup:

- child uses QQ voice/text through the current bot path
- adult stays nearby but avoids answering for the child

## Pre-Trial Checklist

Before starting, confirm:

1. QQ bot can receive and reply normally.
2. Voice reply has sound.
3. Current topic is known.
4. Adult understands that this is not a test score session.
5. Adult will observe, not coach too much.

## Adult Framing Script

Before the child starts, the adult should use a low-pressure intro like:

`We are going to chat with an English speaking buddy. You do not need to be perfect. If you forget a word, you can try your best. If you really get stuck, you can say a little Chinese first, and then try the English sentence.`

Important:

- do not say `answer correctly`
- do not say `be careful`
- do not turn it into homework language

## Trial Success Standard

The session is successful if most of these happen:

- child speaks for at least `4 to 6` turns;
- child gives at least `2` full sentences;
- child accepts at least one retry or scaffold;
- child does not emotionally shut down;
- adult feels the child would probably try again.

## Suggested Topic Order

For the very first trial, use this order:

1. `my-family`
2. `my-favorite-food`
3. `hobbies-and-play`

Why this order:

- familiar;
- emotionally safe;
- easy to answer from lived experience;
- low factual pressure.

Do not start the first trial with:

- weather-and-clothes if the child is not warmed up;
- school-day if the child is tired after school;
- anything that feels like school recitation.

## Suggested 3-Phase Trial Flow

### Phase 1: Warm Start

Time:

- `2 to 3 minutes`

Goal:

- help the child start speaking without pressure

Suggested topic:

- `my-family` or `my-favorite-food`

Observer should watch:

- how long the child hesitates before the first answer;
- whether the child answers with one word or a sentence;
- whether the child smiles, resists, or avoids.

### Phase 2: Guided Expansion

Time:

- `4 to 5 minutes`

Goal:

- see whether the child can move from one-word answers to short sentences

What to watch:

- does the child accept sentence starters?
- can the child add one more detail?
- can the child answer one follow-up question?
- does Chinese rescue help restart the conversation?

### Phase 3: Light Wrap-Up

Time:

- `2 to 3 minutes`

Goal:

- end while the child still feels successful

The adult should not force one more topic if energy is already dropping.

Better to stop with:

- one good full sentence;
- one successful retry;
- one short positive close.

## Observer Note Template

After the session, quickly record:

### Basic Info

- date:
- child age:
- topic used:
- session length:

### Speaking Behavior

- first answer style:
  - silent
  - one word
  - short phrase
  - full sentence
- best sentence today:
- average confidence:
  - low
  - medium
  - high

### Stuck Points

- main difficulty:
  - shy to start
  - cannot recall words
  - cannot build sentence
  - loses attention quickly
  - afraid of mistakes

- did Chinese rescue help?
  - yes
  - no
  - not needed

### Tutor Quality Notes

- which reply worked well?
- which reply sounded unnatural?
- which follow-up felt too hard?
- where did the conversation become smoother?

### Retry Signal

- would the child try again tomorrow?
  - yes
  - maybe
  - unlikely

## What Counts As Good Evidence

Strong positive evidence:

- child starts answering faster after 1 or 2 turns;
- child copies sentence starter and extends it;
- child laughs or keeps talking voluntarily;
- child asks what to say next instead of giving up.

Strong warning signs:

- child waits silently every turn;
- adult must translate almost everything;
- tutor follow-up feels too abstract;
- child becomes tense after correction;
- child treats the session like an oral exam.

## Trial Rules For Adults

During the session, the adult should:

- encourage effort;
- give emotional safety;
- avoid supplying every answer;
- only rescue when the child is truly stuck.

The adult should not:

- correct pronunciation every turn;
- demand perfect grammar;
- compare the child with school performance;
- push the session too long.

## Immediate Post-Trial Decision Rule

After one trial, choose one of three outcomes:

### 1. Continue As Is

Use when:

- child spoke willingly;
- child accepted scaffolds;
- child stayed emotionally okay.

### 2. Continue With Easier Support

Use when:

- child was willing but needed more help;
- one-word answers dominated;
- Chinese rescue helped a lot.

Adjustment ideas:

- use easier topics;
- shorten follow-up chains;
- use more either/or prompts;
- accept more mixed-language transitions.

### 3. Pause and Redesign

Use when:

- child strongly resisted;
- tutor felt too school-like;
- session structure caused stress.

Adjustment ideas:

- shorten to `5 minutes`;
- use hobby/food topic first;
- reduce correction further;
- make opening more playful.

## Recommended Trial Cadence

For early validation:

- test `3 to 5` sessions with the same child if possible;
- do not judge the product from only one session;
- compare topic response differences across sessions.
