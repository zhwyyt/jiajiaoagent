儿童试用脚本 V1

目的

本文件用于给当前 V1 主链路提供一份可重复执行的真实儿童试用脚本：

QQBot + Hermes + jiajiaoagent backend bridge

这份脚本服务于早期可行性验证，不是正式教学评估。

核心想验证 4 件事：

  1. 孩子愿不愿意开口和这个英语陪练聊天？
  2. 孩子能不能在不依赖成人大量救援的情况下持续说上几轮？
  3. 哪些主题最容易带出口语流动感？
  4. 孩子主要卡在哪：词汇、信心、句子组织，还是注意力？

试用形式

建议首轮试用时长：

  • 8 到 12 分钟

建议参与者：

  • 1 个孩子
  • 1 个家长或成人观察者

建议设备与方式：

  • 孩子通过当前 QQ 机器人路径进行语音或文字互动
  • 成人在旁边陪伴，但尽量不要代答

试用前检查

  1. QQ bot 可以正常收到并回复消息
  2. 语音回复有声音
  3. 当前测试主题已确定
  4. 成人知道这不是考试
  5. 成人会以观察为主，而不是不停指导

家长开场引导词

我们现在要和一个英语聊天伙伴说说话。你不用说得很完美，只要大胆说就可以。如果有个词一下子想不起来，可以先说一点中文，再一起试着说成英文。

注意：

  • 不要说“要答对”
  • 不要说“别说错”
  • 不要把这件事说得像做作业

一轮试用算成功的标准

  • 孩子至少说了 4 到 6 轮
  • 孩子至少说出了 2 个完整句
  • 孩子接受了至少一次句型支架或复说引导
  • 孩子没有明显情绪关闭
  • 成人感觉孩子大概率愿意再试一次

建议的首轮主题顺序

  1. my-family
  2. my-favorite-food
  3. hobbies-and-play

原因：

  • 都是孩子熟悉的生活内容
  • 情绪安全
  • 不需要太多知识负担
  • 更容易从真实体验出发说话

建议的三段式试用流程

第一阶段：热启动

时长：2 到 3 分钟

目标：帮助孩子低压力开口

建议主题：my-family 或 my-favorite-food

观察重点：

  • 孩子第一轮前犹豫多久
  • 是单词回答、短语回答，还是句子回答
  • 是愿意说、紧张、回避，还是有兴趣

第二阶段：引导扩展

时长：4 到 5 分钟

目标：看孩子能不能从单词回答慢慢过渡到短句

观察重点：

  • 孩子会不会接句型支架
  • 能不能多补一个细节
  • 能不能回答至少一个追问
  • 卡词时中文救援能不能帮他重新继续说

第三阶段：轻收尾

时长：2 到 3 分钟

目标：在孩子仍然有一点成就感的时候结束

不要为了“多测一个主题”硬拖。更好的收尾方式是停在：

  • 一个说得不错的完整句
  • 一次成功复说
  • 一个积极、轻松的结束点

观察记录模板

基础信息

  • 日期：
  • 孩子年龄：
  • 使用主题：
  • 会话时长：

说话表现

  • 第一反应属于哪种：不说 / 单词 / 短语 / 完整句
  • 今天最好的一句话：
  • 整体信心感受：低 / 中 / 高

卡点观察

  • 主要困难：不敢开口 / 想不起词 / 组不成句子 / 注意力容易掉 / 怕说错
  • 中文救援有没有帮助：有 / 没有 / 没用到

陪练质量观察

  • 哪种回复孩子接得最好？
  • 哪种回复听起来不自然？
  • 哪种追问偏难？
  • 从哪一轮开始对话变顺？

复用意愿

  • 孩子明天还愿不愿意再试：愿意 / 可能愿意 / 大概率不愿意

哪些现象算好信号

  • 孩子第 1、2 轮之后开口速度明显变快
  • 孩子会先模仿句型，再自己加一点内容
  • 孩子会笑、会主动继续接话
  • 孩子会问“这个怎么说”而不是直接放弃

强预警信号

  • 每轮都长时间沉默
  • 成人必须频繁翻译或代答
  • 追问一来孩子就卡住
  • 一纠错孩子就更紧张
  • 整体氛围越来越像口语考试

成人在现场的规则

成人应该：

  • 鼓励努力
  • 提供情绪安全感
  • 让孩子自己先试
  • 只有在真的卡住时再轻微救援

成人不要：

  • 每轮纠发音
  • 强调语法对错
  • 拿学校表现做比较
  • 把时长拖太久

试后快速决策规则

1. 继续照当前方式测

适用情况：孩子愿意说、愿意接支架、情绪状态还不错。

2. 继续，但降低难度

适用情况：孩子愿意，但需要很多支撑；单词回答很多；中文救援帮助明显。

可做调整：

  • 先用更熟悉的主题
  • 缩短追问链
  • 增加二选一问题
  • 更宽容地接受中英过渡

3. 暂停并重设计

适用情况：孩子明显抗拒；整体感觉太像上课或考试；当前互动结构让孩子紧张。

可做调整：

  • 缩成 5 分钟
  • 先从爱好或食物主题开始
  • 进一步减少纠错
  • 让开场更轻松、更像聊天

建议的试用节奏

  • 尽量对同一个孩子做 3 到 5 次短试用
  • 不要只根据一次表现下结论
  • 对比不同主题的反应差异

当前仓库的后续动作

每次按这份脚本试完后，把关键信息写回：

  • STATUS.md
  • TASKLIST.md

如果发现稳定重复的问题，就把它转成后续改动：

  • tutor reply 调整
  • topic pack 调整
  • turn strategy 调整
  • 中英混杂支持调整
